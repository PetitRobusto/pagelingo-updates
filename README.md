# PageLingo Updates

PageLingo Firefox 扩展的公开更新渠道。

- `updates.json`：Firefox 使用的版本清单，由 GitHub Pages 提供。
- Releases：经 Mozilla 签名的安装包。安装后由 Firefox 检查签名并管理后续更新。

当前版本为 [PageLingo 1.3.0](https://github.com/PetitRobusto/pagelingo-updates/releases/tag/v1.3.0)，已通过 Mozilla 审核。请从 Release 附件下载 `pagelingo-1.3.0.xpi`。

固定更新清单：[updates.json](https://petitrobusto.github.io/pagelingo-updates/updates.json)。

旧版如果没有配置本更新渠道，需要手动安装一次带更新地址的签名新版。请在 Firefox 中打开 `about:addons`，选择齿轮菜单 → 从文件安装附加组件，直接覆盖更新以保留设置。

此仓库只用于分发公开版本清单与签名安装包，不收集翻译内容、API 密钥或浏览器设置。
